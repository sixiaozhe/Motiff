# 视频运动时间差分可视化 —— 设计文档

日期：2026-09-19
状态：已批准

## 目标

将视频反色、半透明、并相对原画面时间偏移 N 帧后叠加回原视频，形成时间差分运动可视化（运动残影/拖尾效果）。

## 交付物

一个可复用的 bash 脚本 `motion_diff.sh`，内部通过 ffmpeg 滤镜链实现效果。仅依赖 `ffmpeg`，无其他运行时依赖。

## 接口

```
./motion_diff.sh -i <输入视频> [-o <输出视频>] [-n <帧偏移>] [-a <不透明度>] [-h]
```

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `-i` | 输入视频路径（必填） | 无 |
| `-o` | 输出视频路径 | `<输入名>_motiondiff.mp4` |
| `-n` | 帧偏移。正数=拖尾（叠加 N 帧前），负数=前导（叠加 N 帧后） | `3` |
| `-a` | 反色偏移层的不透明度，范围 0~1 | `0.5` |
| `-h` | 打印帮助并退出 | 无 |

音频默认保留。输出编码为 H.264 + `yuv420p`，确保通用播放器与剪辑软件可播放。

边界处理：`N=0` 会使全画面趋于中灰（无运动信息），视为非法输入并报错退出；`-a` 限定在 `[0,1]`；输入文件不存在时报错退出。

## 核心滤镜链

```
[0:v] split=2 [base][fx]
[fx]  negate → 时移 N 帧 → [fx2]
[base][fx2] blend=all_expr='A*(1-a)+B*a'
```

- `A` = 原图（第一路输入，base），`B` = 反色并偏移后的帧（第二路输入，fx）。
- 表达式等价于标准 alpha 合成：`原图*(1-a) + 反色偏移*a`。
- 用 `blend` 表达式而非依赖特定版本才有的 `all_opacity` 选项，保证兼容性。

### 时移实现

时移完全基于帧数，无需读取帧率，天然支持 29.97 等非整数帧率。

- **拖尾（N>0）**：`negate, tpad=start=N:start_mode=clone`
  - 将反色流延迟 N 帧；当前帧叠加“N 帧前”的反色帧，运动物体后方出现残影。
- **前导（N<0）**：`negate, trim=start_frame=N, setpts=PTS-STARTPTS, tpad=stop=N:stop_mode=clone`
  - 将反色流提前 N 帧；当前帧叠加“N 帧后”的反色帧，残影出现在运动前方。

首尾缺失的帧用克隆帧补齐；`blend` 使用 `eof_action=endall` 让输出长度取两路较短者，保证输出时长与输入一致。整条链在 RGB（`gbrp`）空间运算，使“反色”是真正的 RGB 反相，最后再转回 `yuv420p`。

## 行为特征

- 静态区域：两路内容相同，反色层以 alpha 混合后趋于中灰。
- 运动区域/边缘：两帧内容不同，混合产生明显彩色残影 —— 即时间差分可视化。
- 该“静态变灰”是所描述方法的固有特征，属于预期行为。

## 范围之外（YAGNI）

- 不做逐像素阈值判断/只保留运动边缘的“差分高亮”模式。
- 不做空间位移，仅做时间偏移。
- 不提供 GUI 或批处理入口。

## 测试方案

1. 用 ffmpeg 的 `lavfi` 合成一段带运动的测试视频（移动方块/小球）。
2. 分别以 N>0（拖尾）与 N<0（前导）运行脚本。
3. 校验：脚本退出码为 0；输出帧数、时长、帧率与输入一致；音轨保留。
4. 导出输入与输出的首/中/尾帧截图进行对比，确认残影方向与不透明度符合预期。

## 已知取舍

- 采用用户描述的“反色 + 半透明 + 叠加”公式；另一种“difference 混合模式”能保留暗背景但视觉不同，未采用。
- 残影像素级精度的进一步调节（阈值、颜色融合模式）留待后续按需扩展。
