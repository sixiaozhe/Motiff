# 无残影运动高亮 —— 设计文档

日期：2026-09-19
状态：已实现

## 背景

原 `motion_diff.sh` 采用“反色 + 偏移 N 帧 + 半透明叠加”，残影间距 ∝ 速度 × N，运动越快重影越远。本功能提供一种**无位移残影**的运动可视化：逐像素在当前帧位置判定运动，而不是搬运整帧。

## 交付物

bash 脚本 `motion_highlight.sh`，纯 ffmpeg 实现，无额外依赖。

## 接口

```
motion_highlight.sh -i <输入视频> [-o <输出视频>] [-t <阈值>] [-g <增益>] [-c <颜色>] [-h]
```

| 参数 | 含义 | 默认 |
|------|------|------|
| `-i` | 输入视频 | 必填 |
| `-o` | 输出视频 | `<输入名>_highlight.mp4` |
| `-b` | 不要背景：原画面置黑，只保留运动高亮 | 关闭 |
| `-s` | 透层模式：凡有运动高亮的像素**完全透出原画面像素**（二值），静止区域黑屏 | 关闭 |
| `-x` | 去物/隐形模式：运动物体替换为背景估计（时间中值），物体消失露出背景 | 关闭 |
| `-n` | 背景估计窗口帧数（`-x`），>=3 的奇数；越大去物越彻底但背景变化时易残影 | 15 |
| `-e` | 高亮/物体边缘羽化强度（高斯 sigma）；0=硬边 | 2 |
| `-d` | 差分前时域降噪（`atadenoise`），抑制暗光/噪点引起的闪点 | 关闭 |
| `-k` | 参考帧距：与 N 帧前比较而非相邻帧；>1 填充运动体、减少前后双边缘 | 1 |
| `-t` | 差分阈值 0~255，低于此值当噪声忽略 | 15 |
| `-g` | 高亮增益 >0，越大越亮 | 3 |
| `-c` | 高亮颜色 6 位十六进制 RRGGBB | `ffffff` 白 |
| `-h` | 帮助 | |

音频默认保留；输出 H.264 + `yuv420p`。

## 核心滤镜链

```
[0:v] format=gbrp, split=2 [base][d]
[d]   tblend=all_mode=difference, format=gray,
      lut=y='if(lt(val,T),0,min(255,(val-T)*G))',
      format=gbrp, lutrgb=r='val*R':g='val*G':b='val*B'
[base][hi] blend=all_mode=screen, format=yuv420p
```

- `tblend=all_mode=difference` 得到相邻帧差 `|I_t − I_{t-1}|`；`-k N` 时改用 `split` + `tpad=start=N` 延迟 N 帧再 `blend=difference:shortest=1`，得到 `|I_t − I_{t-N}|`（已实验验证对齐正确、帧数不变）。
- `-d` 在差分前插入 `atadenoise` 做时域降噪，抑制暗光闪点。
- `lut` 做阈值 + 增益，抑制压缩噪声。
- `lutrgb` 把单通道蒙版染成目标颜色。
- `screen` 叠加回原帧：静态区不变，运动处以原色 + 高亮色增亮。
- 加 `-b` 时去掉 `split`/`base` 与 `screen`，直接输出染色后的差分，即黑底上只有运动高亮。

### 透层模式（`-s`）

目标：凡有运动高亮的像素**完全透出原画面**（二值），静止（无高亮）处黑屏，**不向外膨胀**。

```
[0:v] format=gbrp, split=2 [base][d]
[d]   tblend=all_mode=difference, format=gray,
      lut=y='if(lt(val,T),0,255)',   # 二值: 超过阈值即完全透出
      gblur=sigma=e,                 # 可选, 仅羽化边缘(核心仍为 255)
      format=gbrp                    # 复制成三通道蒙版
[base][m] blend=all_mode=multiply    # base * mask/255 (高亮处=原样, 其余=黑)
```

- 阈值二值化后不做 `dilation`，所以运动区域不会被向外扩散；有高亮的像素一律完全透出原画面。
- `-e` 的高斯模糊后**不再重新二值化**：核心保持 255（完全透出），只把边缘羽化成柔和过渡；`-e 0` 为严格硬边。
- 需要透层模式时 `-b`/`-c` 不再有意义。
- 必须用 **planar `gbrp`**：`blend` 在 packed `rgb24` 下通道错乱（会产生洋红整帧），已验证。

### 去物/隐形模式（`-x`）

目标：把运动的人/车等物体替换为其所在位置的**背景估计**，物体消失、露出背景。

```
[0:v] format=gbrp, split=2 [base][tb]
[tb]  tpad=start=r:start_mode=clone:stop=r:stop_mode=clone,
      tmedian=radius=r, setpts=PTS-STARTPTS [bgs]     # r=(n-1)/2
[bgs] split=2 [bg1][bg2]
[base] split=2 [cur][cmp]
[cmp][bg1] blend=all_mode=difference, format=gray,
      lut=y='if(lt(val,T),0,255)', gblur=sigma=e, format=gbrp [m]
[cur][bg2][m] maskedmerge, format=yuv420p
```

- 背景用 `tmedian`（逐像素时间中值）估计：短时间内经过的物体不会占据中值，于是被抹掉。
- `tmedian` 会丢弃首尾各 r 帧，因此前后各 `tpad` 补齐 r 帧再 `setpts` 复位，**帧数与对齐均不变**（已实验验证：与逐像素中值完全一致、0 处不一致）。
- 物体掩膜由 `|当前帧 − 背景|` 阈值得到，`-e` 羽化边缘；`maskedmerge` 在掩膜处取背景、其余取当前帧。
- `-n` 是窗口帧数（`2r+1`）：越大越能去掉慢速物体，但背景本身变化时会出现残影/拖影。
- 注意：一个 filtergraph 输出标签只能连一个输入，`[bgs]`/`[base]` 都必须 `split` 后再分别使用。
- 相机运动时背景估计失效（整帧都在动），此模式只适合固定机位。

## 行为特征

- 静态背景（无论多复杂）**完整保留**。
- 运动物体在**当前位置**被高亮，无位移重影；速度表现为亮度。
- 快速运动时前后缘可能出现两条靠得很近的高亮边（帧差分的固有特性），但不会出现整块分离的重影。

## 调参建议

- 低码率/噪声大的素材：提高 `-t`（如 25~40）。
- 高亮太弱：提高 `-g`；太刺眼：降低 `-g` 或降低 `-c` 的亮度。
- 需要不同风格：改 `-c`（如 `00ff66` 绿、`00b3ff` 蓝）。

## 测试

`tests/test_highlight.sh`：合成运动方块视频，断言静态角落保持黑色、运动处出现橙色高亮、透层模式静止黑屏且运动处透出原样像素、`-k`/`-d` 组合、`-x` 去物（运动方块被背景替换）、输出 50 帧，以及参数错误处理。当前 21/21 通过。

## 范围之外

- 不做光流幅度/方向热力图（已对比，观感更好但需 OpenCV，且噪声难调）——需要时可另作扩展。
- 不做运动矢量箭头。
